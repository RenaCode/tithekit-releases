# TitheKit releases

Release binaries of **TitheKit** (macOS, Apple silicon). This repository holds
only the release archives and their SHA-256 sums. It contains no source code.

Install:

```sh
brew install renacode/tap/tithekit
```

Project page: https://tithekit.com

License: proprietary. The binaries may be downloaded and used under the TitheKit license, which is
included inside every archive. Redistribution is limited to what that license allows. Releases are
published automatically from the private build repository; check each archive against its `.sha256` file.

Supported versions: only the latest release is supported and receives security fixes. Older releases kept in this
repository are unsupported and may have unpatched vulnerabilities; use them at your own risk. To report a
vulnerability, see [SECURITY.md](SECURITY.md).

# TitheKit: wydania

Gotowe binarki **TitheKit** (macOS, Apple silicon). To repozytorium zawiera wyłącznie archiwa wydań
i ich sumy SHA-256. Nie ma w nim kodu źródłowego.

Instalacja:

```sh
brew install renacode/tap/tithekit
```

Strona projektu: https://tithekit.com

Licencja: własnościowa. Binarki można pobierać i używać na warunkach licencji TitheKit, dołączonej do
każdego archiwum. Wydania są publikowane automatycznie z prywatnego repozytorium budowania; sprawdź
archiwum z plikiem `.sha256`.

Wspierane wersje: wspierana jest tylko najnowsza wersja i tylko ona dostaje poprawki bezpieczeństwa. Starsze wydania
w tym repozytorium nie są wspierane i mogą mieć niezałatane podatności; używasz ich na własne ryzyko. Zgłaszanie
podatności: zob. [SECURITY.md](SECURITY.md) (po angielsku) albo https://tithekit.com/pl/security/.
